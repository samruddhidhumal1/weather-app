# Weather Web Application

This is a simple weather web application built using Python Flask.  
The application allows users to search for a city and view the current weather information.

## Features
- Search weather by city name
- Displays temperature and weather condition
- Simple and responsive user interface
- Fetches real-time weather data using Weather API

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Weather API

## Project Structure
weather-app
│
├── app.py
└── templates
    └── index.html

## How to Run
1. Install Python
2. Install Flask
3. Run the application

4. Open browser and go to:http://127.0.0.1:5000
